# Agent Eval Public Notes

Short, reusable notes for evaluating tool-using AI agents in practical engineering workflows.

This repository collects compact templates and checklists that support the public research artifacts around lightweight agent evaluation, operational scorecards, trajectory replay, and small-rule guardrails. The goal is to make the work useful outside a paper or demo: a builder should be able to copy one note, adapt it to a real system, and get a better evaluation loop the same day.
